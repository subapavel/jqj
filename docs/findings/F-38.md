# F-38 — The ticket gate enforces a required list only when told to

- **Assumption** (ADR-0020; `scripts/gate-ticket.sh`): a ticket's required oracle cases are enforced
  at its gate.
- **How it fails**: the gate passes `-Doracle.require` only when `ORACLE_REQUIRE` is set, and neither
  `/run-spec` nor the verifier's instructions said to set it. #61's first gate ran without it.
- **Severity**: major (a required case could stay red through the gate).
- **Evidence**: #61 gate on 937faaf (verify-61); spec review noted the green of `require/61.txt` as
  NOT_RUN. No spec-2a ticket merged before #61 has a require file, so nothing merged unchecked.
- **Change made**: `/run-spec` §2 step 2 and `.claude/agents/verifier.md` say to set `ORACLE_REQUIRE`
  when `require/<ticket>.txt` exists; #61 re-gated with it. A gate that picks the file up by itself is
  a candidate for the spec retro.
