# F-77 — The pipe is a hold, so the conservative compile detaches at every read

- **Assumption**:
  - ADR-0007 "Holds and retention": a view of an input document "is detached only when it enters a
    hold that spans a later read: a variable, an accumulator, an array being built, an error
    payload, or a closure or group that reads."
  - ADR-0018 and GLOSSARY "Conservative compile": the conservative compile detaches "at every hold".
- **How it fails**:
  - The list misses the `.` a node keeps while it reads input. On stdin `1 2 3`,
    `def f(g): [g, g]; input | f(., input)` → `[1,2,1,3]`.
    - Once the Resolver inlines `f` (ADR-0040), no closure is left.
    - The first document is the right side's `.`, and it is read again after the second `input`
      has replaced it. No listed hold covers it, and a missed hold raises the stale-view error.
    - `input | [., input]` → `[1,2]` is the plain case.
  - Under "detach at every hold" the conservative compile uses the same hold list as the optimised
    compile, so both miss the same hold. Both end in the same termination, which the compile-mode
    oracle leaves out (ADR-0020), so the oracle cannot see the miss.
- **Severity**: major (a filter jq runs ends with STALE_VIEW).
- **Evidence**: spec 5 grilling round 1, question 7.
- **Change made**:
  - A hold is every place a value stays live across a node that may read input, that node's own
    `.` included. "May read input" is a per-group fact computed as may-break-out is, from
    Operation's `reads` fact; no IR kind is added.
  - In spec 5a both compiles detach every `input` document at its read. Spec 5b adds the hold
    analysis to the optimised compile only; the conservative compile keeps detaching at each read.
  - ADR-0007, ADR-0018 and the glossary ("Hold", "Conservative compile") are amended. On the
    adviser's list for the owner (2026-11-16).
  - Spec 5 round 2, proposed by the grilling-adviser for the owner under the delegation of
    2026-11-14, sharpens this: may read input with one bit per closure parameter, entry and store
    hold sites, a hold's detach of input-document views only (ADR-0007's "Amendment (spec 5 round
    2)"), and `reads` as the input stream only (F-79, F-80; `docs/wayfinder/spec-5-grilling.md`,
    "Round 2").
