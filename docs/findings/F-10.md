# F-10: The `path(.a | true)` deviation row was wrong

- **Assumption** (ADR-0007, `DEVIATIONS.md`): `{"a":1} | path(.a | true)` gives `["a"]` on jq.
- **How it fails**: jq-ref 1.8.2 raises "Invalid path expression with result true" on `{"a":1}`.
  It gives `[["a"]]` only on `{"a":true}`, where the result happens to equal the value at the path.
- **Severity**: minor (a documentation error; no code depended on it).
- **Evidence**: issue #7 round 2, the adviser; checked again by the architect.
- **Change made**: the `DEVIATIONS.md` row and ADR-0007 now use the input `{"a":true}`.
