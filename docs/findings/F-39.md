# F-39 — JOL is GPL-2.0, so it cannot measure the bytes-built charges

- **Assumption** (ADR-0017, bytes built): the fixed charge per built container and per built string
  is measured with JOL or `-prof gc`.
- **How it fails**: JOL (OpenJDK Code Tools) is GPL-2.0 with no allowed alternative; the licence list
  in `CLAUDE.md` admits only JMH as an exception, in the benchmark module.
- **Severity**: minor (an alternative was already named).
- **Evidence**: #64 design draft; JOL's licence on its project page.
- **Change made**: ADR-0035 measures both charges with JMH `-prof gc` only; ADR-0017's status records
  the amendment.
