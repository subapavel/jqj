# F-35 — The census gives string interpolation to the lexer ticket

- **Assumption** (ADR-0005, `scripts/census.java` line 633): interpolation is a lexer feature, so its
  cases need only S2a.11.
- **How it fails**: ADR-0005 lowers interpolation to nested `Bind`s, which arrive with S2a.17
  (#67). A one-part `Pipe` in S2a.11 would contradict the ADR. With interpolation in S2a.11, S2a.15
  counts man.test#a5504f7a733e (two parts plus `+`) as a gate case it cannot pass before S2a.17.
- **Severity**: major (a gate case that cannot go green in its ticket).
- **Evidence**: #61 designer draft, open point 1; architect's approval on #61; hand-over on #67.
- **Change made**: the census gives the `interp` need to S2a.17; bare `@text` (format `text`) stays
  with S2a.11. The census change, `census write` and `census gate 56` are part of #61 (its
  test-author). No ADR is amended; ADR-0005 stands.
