# F-37 — The run deadline reads the system clock, which tests cannot fake

- **Assumption** (ADR-0017, ADR-0030; CODING_STANDARDS, Tests): the deadline reads
  `System.nanoTime()`; tests use no sleeps and a fake clock drives time.
- **How it fails**: the deadline's clock is not behind a port, so "the deadline counts from
  `begin`" and the deadline comparison have no witness (#59 mutants M10, M24 survive).
- **Severity**: minor (the behaviour is right by reading; it is unpinned).
- **Evidence**: #59 standards review; `.logs/59-mutants*.log` in the #59 worktree.
- **Change made**: none in #59 (accepted there). Ticket #79 adds a package-private clock seam in
  `RunState`; no exported signature changes and ADR-0017 stands.
