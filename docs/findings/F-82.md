# F-82 — A module path in stderr changes with every case directory

- **Assumption**:
  - ADR-0020 "The differential oracle": `scripts/oracle-record.sh` "runs jq-ref in a fresh
    directory per case", "runs each case twice … and rejects a case whose two runs differ", and
    the comparison is "the exit code, stdout and stderr, byte for byte".
  - ADR-0020 "The jqtest oracle": "The host is `Host.sandboxed()` with UTC, a `ModuleLoader` over
    the copied `tests/modules`".
- **How it fails**:
  - `CaseDirectory` makes the case directory with `createTempDirectory`, so its path changes per
    run. jq prints a module's real path in stderr and stdout: "circular import of
    <scratch>/p7/m/cycle_a.jq", a syntax-error block "at <scratch>/p7/m/syntaxerror/syntaxerror.jq,
    line 1, column 4", `$__loc__.file`, `get_search_list` and `get_prog_origin`.
  - Such a case differs between its two recording runs and is rejected, so the module cases that
    print a path cannot be recorded, and a jqj run in another directory could not match them.
  - The jqtest host's loader is not named; spec 7 puts linker.c's rules in jq-cli's
    `FileModuleLoader` (F-81), so a second loader in `oracle` would drift and check 1 would test
    the copy.
- **Severity**: minor (an oracle rule; no product behaviour changes).
- **Evidence**: spec 7 grilling round 1, open point "absolute path in stderr"
  (`docs/wayfinder/spec-7-grilling.md`), proposed by the grilling-adviser for the owner under the
  delegation of 2026-11-14; jq-ref 1.8.2 probes P2, P4 and P6;
  `oracle/src/main/java/io/github/subapavel/jqj/oracle/diff/CaseDirectory.java`.
- **Change made**:
  - ADR-0020 gains "Amendment (spec 7 round 1; F-82)": the recorder and the comparison replace
    every occurrence of the case directory's real path in stdout and stderr with `<case>`, on
    jq-ref's output when recording and verifying and on jqj's when comparing. The jqtest host's
    loader is jq-cli's `FileModuleLoader` with lib dir `tests/modules`.
  - Spec 7's first ticket (T1) builds the token, before any module case is recorded.
  - On the adviser's list for the owner (2026-11-16).
