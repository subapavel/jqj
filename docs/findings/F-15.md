# F-15: jq's error text is part of what jqj matches

- **Assumption** (founding §1, repeated in ADR-0016's versioning): "Not goals: … identical error
  message wording".
- **How it fails**: jq programs and scripts read error text. jq.test compares caught messages, and
  13 of its `%%FAIL` cases check compile messages. ADR-0015 already chose jq's parse-error texts.
- **Severity**: minor.
- **Evidence**: issue #15 round 1 (the designer's draft and the adviser's evaluation, posted on #15).
- **Change made**: ADR-0020: jqj matches jq's text wherever a filter or a script can read it, and
  keeps its own text for syntax errors only (one `DEVIATIONS.md` row). Founding §1's not-goal is
  superseded by ADR-0020 and reads as "identical syntax-error wording". ADR-0016's semver exclusion of message wording stays,
  because a text can change with the reference.
