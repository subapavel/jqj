# F-52 — ADR-0005's node list names `Empty` and leaves out the nodes added since

- **Assumption** (ADR-0005, "Nodes"): `Empty` is a Flow node; the list is the IR's kinds.
- **How it fails**: `Node.java` permits 18 records and no `Empty`: `empty` is the Operation
  `Intrinsic(empty)` (`internal/op/Empty.java`), and `try E` takes it as its handler (`ir/Try.java`).
  `Advance` (ADR-0041) and `Binds` (ADR-0043) are kinds the list does not show. `Call`, `ParamCall`
  (2b, ADR-0040) and `PathOf`, `Update` (spec 3) are not built yet. ADR-0043's count of 22 is the
  design's: ADR-0005's 21, less `Empty`, plus `Advance` and `Binds`.
- **Severity**: minor (wording; the code and the verifier agree).
- **Evidence**: spec 2a review (#56, reviewer-standards, query-core); `Node.java:7` at 26a9628.
- **Change made**: ADR-0005's list is amended to drop `Empty`, add `Advance` and `Binds`, and say
  which kinds are built at the end of 2a. ADR-0005 points here.
