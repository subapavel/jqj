# F-18: ADR-0020 contradicts itself on `values-v1` and on `compile.txt`

- **Assumption** (ADR-0020 "Generated cases" and "Ratchet"): `values-v1` is "spec 1, widened in
  spec 5", and "a changed generator gets a new name"; `compile.txt` has one line per case id, and
  ADR-0022 adds a copy-only run to the compile-mode oracle.
- **How it fails**: widening `values-v1` changes it, so by the naming rule it would need a new
  name. With one line per id, the copy-only run's arrival must either keep a line whose case now
  terminates under copy-only (wrong) or drop it (a ratchet drop the verifier refuses).
- **Severity**: minor.
- **Evidence**: issue #17 round 1 and the ADR review (the adviser's evaluation, recorded on #17).
- **Change made**: ADR-0023: `values-v1` is recorded whole in spec 1 and what passes is ratcheted,
  so "widened" means more of its cases pass; `compile.txt` gets a `mode` column, one line per mode.
  ADR-0020 amended.
