# F-28 — Spec 1's PR: trailer waiver, gate time targets, ADR-0028 confirmed

Owner decisions at PR #48, 2026-11-12. The owner accepted all seven recommendations of the
`grilling-adviser`.

- **Assumption** (ADR-0014: the trailer check, ticket gate step 1, the spec gate; ADR-0020: PIT
  and seeds):
  - every commit between `main` and the head carries the trailers;
  - ticket gate step 1 is under 60 s with three gates in parallel;
  - the spec gate's PIT has no time target.
- **How it fails**:
  - Eight architect docs/handoff commits on `spec/22-walking-skeleton` lack `Ticket:`,
    `Co-authored-by` or `Signed-off-by`: 582cdaa c176ef9 8daabc1 6998da3 608ae11 6898629 a6f15e3
    6cad449. The PR's `trailers` job is red over 209 commits; these 8 are the only failures.
    Rewriting them would change the SHA of all 209 commits, because 582cdaa is the first, and
    every SHA cited as evidence would go stale.
  - Step 1 measured 70.2 to 71.4 s with three gates in parallel, and 27 to 30 s alone (#40).
  - The spec gate's PIT over query-core, jq-core and oracle measured about 24 min (52d0c5d),
    growing with mutants × tests, against the nightly's 60-min timeout.
- **Severity**: major. CI on `main` and the gates of every later spec depend on it.
- **Evidence**: PR #48 CI run (pull_request, `trailers` red); `bench/RESULTS.md` "Ticket-gate steps
  (#40)"; the spec-gate steps at 52d0c5d (`pit` 1442 s); the adviser's hand-back on PR #48.
- **Change made**:
  - **Trailer waiver.** `scripts/trailers-waiver.txt` lists exactly those eight commits by full
    SHA, and `scripts/check-trailers.sh` skips only a listed SHA. A new line in that file is
    owner-only. No history rewrite.
  - **Spec merge commit.** It carries the trailer block in its body (`gh pr merge --merge
    --body-file`), because the push run on `main` checks it. A merge from the web UI with the
    default message turns `main` red.
  - **Ticket gate step 1.** The target is now under 120 s with three gates in parallel. If a spec
    gate measures more, the named fallbacks apply by a finding, with no owner round: first a
    step-1 profile by module and plugin, then no `-Pbench` in the ticket gate unless the ticket
    names `bench`.
  - **Spec-gate PIT.** The target is under 45 min alone on `claude-cloud-4vcpu`, so the nightly
    stays inside its 60-min timeout. If a spec gate measures more, ADR-0020's fallback applies by
    a finding, with no owner round: group the generated seeds per unit, or keep them out of PIT.
  - **Required checks.** `trailers`, `build` and `windows` become required on `main`. The owner
    sets this after the waiver is green on the PR and before the merge.
  - **Nightly.** `nightly.yml` is dispatched once after the merge, and the run is linked on #31.
  - **G7.process** (about 130–140 ms) is only noted. Spec 7 measures how the time splits before
    any CDS or AOT-cache ticket.
  - **ADR-0028** is confirmed by the owner as written.
  - ADR-0014, ADR-0020 and ADR-0028 are amended to point here.
