# F-8: GATE check 4 names a deadline but no step budget and no recursion-depth budget

- **Assumption** (`docs/GATE.md` check 4): the budgets are nesting depth, bytes built, bytes
  written and deadline. Founding architecture §6 says "steps or time".
- **How it fails**:
  - A deadline alone gives no reproducible cut-off, so budget tests would depend on the clock.
  - Issue #7 round 1 added a recursion-depth budget.
- **Severity**: minor.
- **Evidence**: issue #7, rounds 1 and 2.
- **Change made**:
  - ADR-0008 has a step budget and a deadline. ADR-0011 has a recursion-depth budget.
  - The check 4 wording now lists them all; the budget is a `Termination` that no filter can
    catch.
