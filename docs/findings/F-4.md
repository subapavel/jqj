# F-4 — Streaming is not automatic

- **Assumption** (founding architecture §3 table, §6.7): streaming is chosen automatically when the
  filter allows it.
- **How it fails**: on jq-ref 1.8.2, `{"items":[1,2,3],"z":tru}` with `.items[]` or
  `first(.items[])` gives a parse error and no results (rc 5), and `{"items":[1],"items":[2]} |
  .items[]` gives `2`. A streamed run would already have emitted results. Automatic streaming would
  also make the behaviour depend on whether the analysis succeeds: adding `. as $r |` flips it.
- **Severity**: major.
- **Evidence**: issue #6, round 1 (observed by the grilling adviser).
- **Change made**: ADR-0007. Root use reports eligibility only, streaming is off unless the host
  enables it, the CLI reads whole documents, and the enabled mode's differences are in
  `DEVIATIONS.md`. The switch belongs to "What are the public API, the host SPI and the sandbox?".
