# F-23 — The #32 answer "no tick call site" contradicted spec 1's grilling

- **Assumption**: the architect's answer Q5 on #32 ("drop the `tick` call site until spec 2, so no
  unobservable code ships now").
- **How it fails**: `docs/wayfinder/spec-1-grilling.md` round 1 item 1, which the owner approved, says
  "the reader and writer get their tick call sites now". The answer reversed an owner decision without
  a finding.
- **Severity**: minor.
- **Evidence**: the designer's draft for #33 (conflict C10), 2026-11-11.
- **Resolution**: #33 adds the call sites the owner asked for. `Workspace.tick(int steps)` adds to a
  package-private step counter (one step per started KiB read or printed). Nothing enforces it until
  spec 2 wires `Limits.steps`, but a below-API test observes the counter, so the call sites are tested
  and PIT can kill them.
