# F-5 — Recursive builtins stay prelude definitions

- **Assumption** (founding architecture §3 table, §8): hot and recursive builtins (`map`, `select`,
  `recurse`, `limit`, `while`, `until`, `repeat`, …) are native loops.
- **How it fails**: in jq 1.8.2 these are jq definitions (`src/builtin.jq`), and their path
  behaviour comes with them (`path(limit(2; .[]))` and `path(..)` work). Every native loop would
  need a hand-written path variant. Specialisation plus tail jumps make them loops anyway
  (ADR-0006).
- **Severity**: minor.
- **Evidence**: issue #6, round 2.
- **Change made**: ADR-0006. The natives are `range/2`, `inputs` and `flatten`; any other builtin
  becomes native only on a measured win, with its own path variant.
