# F-11: In path mode `.a?` is not a `Try`

- **Assumption** (ADR-0005): "`.a?` lowers to a `Try` that folds into the operation's quiet
  variant".
- **How it fails**: on jq-ref 1.8.2, `[path(1|.a?)]` raises ("Invalid path expression … access
  element "a" of 1", rc 5), while `[path(1|try .a)]` and `[path(1|(.a)?)]` give `[]`. The quiet step
  suppresses value errors but not path-validity errors.
- **Severity**: minor.
- **Evidence**: issue #7 round 2 and the ADR review (adviser); checked again by the architect.
- **Change made**: ADR-0005 folds `.a?` into the quiet variant in the value variant only. ADR-0009
  states that the quiet variant still raises path-validity errors.
