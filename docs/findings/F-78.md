# F-78 — `malformed-v1` has no GATE check 2 minimum

- **Assumption**:
  - ADR-0023 "Generator minimums" and GATE check 2: 1000 cases each for `values-v1`, `core-v1`
    and `ownership-v1`, and 200 for each builtin family. A minimum "may be raised freely and
    lowered only by a finding".
  - ADR-0020's spec 5 round 1 amendment adds `malformed-v1`, a frozen generator of malformed
    input whose forms cover GATE check 3's routes and modes (`-c .`, `try input catch .`, `-s`,
    `--seq`, `--stream`, `fromjson`).
- **How it fails**:
  - No minimum names `malformed-v1`, so the gate would pass with any number of its cases,
    zero included, and a form whose seeds all drop would leave its route unchecked.
  - Round 1's records round left the question open ("whether `malformed-v1` gets a GATE check 2
    minimum").
- **Severity**: minor (no case is wrong; the gate could pass with a route of check 3 untested).
- **Evidence**: spec 5 ticket approval, section 5 (`docs/wayfinder/spec-5-grilling.md`,
  "Ticket approval").
- **Change made**:
  - `malformed-v1` has a minimum of 200 cases per form in `differential.txt`, counted after
    ADR-0020's drops, as each builtin family has. Its generator ticket records 1 800 seeds
    (300 per form, form by `seed % 6`).
  - ADR-0023 is amended, and GATE check 2's text names it. Changing a GATE check is the
    owner's to confirm: on the adviser's list for the owner (2026-11-16).
