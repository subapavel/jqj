# F-9: `last/1` is not a prelude definition in jq 1.8.2

- **Assumption** (ADR-0006): the only natives are `range/2`, `inputs` and `flatten`, and every
  other builtin is jq's own prelude definition.
- **How it fails**: `builtin.jq` 1.8.2 defines only `last/0`. `last/1` is bytecoded in `builtin.c`
  (`gen_last_1`). A `reduce` definition would be wrong: on jq-ref, `[last(empty)]` gives `[]`,
  where `def mylast(f): reduce f as $x (null; $x); [mylast(empty)]` gives `[null]`, and
  `path(last(.[]))` raises.
- **Severity**: minor.
- **Evidence**: issue #7, designer draft and round 1 (adviser; checked again by the architect).
- **Change made**: ADR-0009 adds `last/1` as a native without a path variant (amends ADR-0006).
