# F-6 — Navigation is an operation, not a node kind; touched fields waits for a consumer

- **Assumption** (founding architecture §7): field, index, slice, iterate and object construction
  are IR node kinds, and a touched-fields analysis feeds the reader's skipping.
- **How it fails**:
  - Format-specific node kinds in `query-core` would break §14.
  - ADR-0002 has no tape entry for a skipped subtree, so touched fields has no consumer yet.
- **Severity**: minor.
- **Evidence**: issue #6, rounds 1 and 2.
- **Change made**: ADR-0005 makes navigation steps `Operation`s called through `Intrinsic`, and
  object construction lowers to `Bind`s. ADR-0007 keeps touched fields as a contract, built when
  "How do the JSON reader and writer behave?" adopts skipping.
