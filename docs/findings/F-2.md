# F-2 — Views go stale without an Arena

- **Assumption** (founding architecture §6.2): input documents sit in an `Arena`, and a stale view
  throws once the arena is closed.
- **How it fails**: Spike B showed that the tape must be reused from the `Workspace` (a fresh tape
  per read costs 1.2–1.8×), so a heap document's views also go stale at the next read, with no
  arena involved.
- **Severity**: minor.
- **Evidence**: `bench/RESULTS.md` "Spike B"; issue #5.
- **Change made**: ADR-0004 gives each read a new `JsonDoc` and drops the previous one's tape and
  bytes; a stale view raises the stale-view error whether or not an arena backs the bytes.
