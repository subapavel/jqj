# F-24 — ADR-0015's whole-container copy would copy whitespace inside the container

- **Assumption**: ADR-0015 "Whole-container copy" lists its conditions: compact mode without `-S`,
  `-a` or `-C`, and every entry null, a boolean, tag 5, CANONICAL or a container, with no repeated key
  and the depth within the print limit.
- **How it fails**: none of these conditions excludes whitespace between the container's tokens. Under
  `-c`, copying the bytes of `[1, 2]` would print the space, where jq prints `[1,2]`.
- **Severity**: major for spec 6, which ships the copy; nothing in spec 1 copies a container.
- **Evidence**: the designer's draft for #33 (conflict C11), 2026-11-11.
- **Resolution**: open, for spec 6's grilling. The walk must also prove the container holds no
  whitespace (the reader can flag it, as it flags CANONICAL), or the copy is dropped.
