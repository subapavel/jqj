# F-20 — ADR-0016 calls all six kinds sealed interfaces, and a Stub can pass a FAIL-shaped case

- **Assumption**:
  - ADR-0016 ("the six kinds are public sealed interfaces") against ADR-0003 (`JqNull` and `JqBool`
    are enums).
  - ADR-0020's FAIL and syntax-error rules against GLOSSARY "Stub" (its cases score FAIL).
- **How it fails**:
  - The two ADRs contradict each other on the null and boolean kinds.
  - A `%%FAIL` case that checks only that compiling fails, or a differential case recorded as a
    syntax error (rc 3, stdout compared), passes when jqj ends with a Stub.
- **Severity**: minor.
- **Evidence**: the designer's draft for #24 (conflicts C1 and C2), 2026-11-11.
- **Change made**: ADR-0024 accepted. ADR-0016's sentence now reads "the four kinds with views are
  public sealed interfaces; `JqNull` and `JqBool` are enums". ADR-0020 gains the Stub-first verdict
  rule. The class-path sealed proof that ADR-0016 gave to "the skeleton ticket" is #24's.
