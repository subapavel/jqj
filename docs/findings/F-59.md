# F-59 — A pattern's steps and a loop's source run in path mode, against ADR-0010's "bound values run in value mode"

- **Assumption**:
  - ADR-0010 "Who passes the path on": `Bind`, `AltBind`, … "pass it on unchanged. Their
    conditions and bound values run in value mode"; "`Foreach` binds its item as a (value, path)
    pair".
  - ADR-0038 and ADR-0041: patterns and loop sources lower to plain Binds, with nothing there for
    a path variant to read.
- **How it fails**: jq runs a pattern's matcher steps and a `reduce`/`foreach` source in path mode.
  Value mode then returns results where jq-ref raises, which is the direction `DEVIATIONS.md`
  never allows:
  - `path(reduce ([1]|.[]) as $x (0;1)|empty)` raises "…near attempt to iterate through [1]"
    (`foreach` alike); in value mode it gives nothing.
  - `(.a as [$x] | .b) |= 5` raises "…near attempt to access element 0 of [1]"; value mode sets
    `.b`.
  - `{"a":["b"],"b":0,"c":0} | (.a as [$x] ?// $x | if ($x|type)=="string" then .b else .c end)
    |= 1` → `{"a":["b"],"b":0,"c":1}`; value mode takes the first alternative and sets `.b`.
  - A plain `as` source stays in value mode (`path(([1]|.[]) as $x|.)` → `[]`). On
    `{"a":[1],"b":0}`, `.a as $v|[path(($v|.[0]) as $x|.b)]` → `[["b"]]` while
    `[path(.a as [$x]|.b)]` raises, so the IR's shape cannot tell the two apart.
- **Severity**: major (results where jq raises; a different object in the `?//` case).
- **Evidence**: spec 3 grilling round 1, question 4 and A1; round 2, question 4.
- **Change made**:
  - `Tracking {VALUE, PATH, ITEM}` on Bind, on each Binds value and on an AltBind's value
    (ADR-0048): PATH on a pattern's index steps and on a loop source, ITEM on the source of
    `foreach … as $name`.
  - ADR-0010's Bind rule and its Foreach item, ADR-0038 and ADR-0041 are amended.
  - `DEVIATIONS.md` gains rows where jq continues by a quirk: `foreach … ?//`, and four more at
    spec 3's ticket approval (grilling-adviser for the owner under the delegation of 2026-11-14):
    `[[1],[2]] | [path(foreach .[] as [$a] (0; 1; $a))]`,
    `[[5],[6]] | [path(foreach .[] as $x (0; $x; .))]`, `[1,2] | path(. as [$a,$b] | $a)` (jq
    names element 0, jqj element 1) and
    `["x","y"] | (. as [$v] ?// $v | if ($v|type)=="string" then $v else .[1] end) |= "Z"`. The
    `?//` row is a different value, not an error; it is on the owner's list. The
    `. as [$a] | $a` row stays.
  - ADR-0010's Bind rule is owner-accepted text, so this is on the adviser's list for the owner
    (2026-11-16).
