# F-21 — The tape size limits are stated as powers of two that the entry's fields cannot hold

- **Assumption**: ADR-0002:39-40, ADR-0015:52-53 and DEVIATIONS "Size limits of the tape" give
  "256 MiB per string", "16 MiB per number literal" and "2^28 entries per container".
- **How it fails**: the string span is 28 bits (quotes included), the number length 24 bits and
  the container span 28 bits, so the largest legal values are 2^28−1 bytes, 2^24−1 bytes and
  2^28−1 entries. A test at "256 MiB" would test a value the tape cannot hold.
- **Severity**: minor.
- **Evidence**: the designer's draft for #32 (conflict C2), 2026-11-11.
- **Resolution**: the three texts now say 2^28−1 bytes per string (quotes included), 2^24−1 bytes
  per number literal and 2^28−1 entries per container. ADR-0002 now also states the document limit as
  F-12's 2^31−3 bytes, which ADR-0015 had already amended.
