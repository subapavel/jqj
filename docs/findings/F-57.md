# F-57 — No IR fold pass, against ADR-0006's pass order

- **Assumption**: ADR-0006 "Passes": "resolve → inline and specialise → fold → freeze → analyses".
  Spec-2 grilling round 1, Q1 (owner, 2026-11-12) puts "folding" in 2b.
- **How it fails**:
  - jq folds only while parsing (`--debug-dump-disasm`: `1+2` is `LOADK 3`, `def f: 1; f+2` keeps
    `CALL_JQ f:0`), and 2a built that fold (ADR-0034, #65).
  - An IR fold runs after inlining, so it would fold what jq keeps as a call. It adds no jq
    behaviour: it is an optimisation with no measured win, and one more pass for the verifier and
    the compile-mode oracle to check.
- **Severity**: minor.
- **Evidence**: spec 2b grilling round 1, Q10; the jq-ref `--debug-dump-disasm` probe quoted above.
