# F-22 — ADR-0015 counts two depth slots per open object; jq counts one, plus one per open key value

- **Assumption**: ADR-0015 "Depth": "one per open array, two per open object".
- **How it fails**: on jq-ref 1.8.2, 9 999 `[` around `{}` and around `{"a":1}` both read, while
  9 999 `[` around `{"a":[]}` fails at line 1, column 10005. A reader that adds two at `{` rejects the
  first two. The ADR's "objects nest 5 000 deep" still holds, because every nested object sits in an
  open key value (`{"a":` × 5 001 fails at 1:25001).
- **Severity**: minor.
- **Evidence**: the test-author's jq-ref observations for #32, pinned in `MalformedDocumentTest`
  (`depthLimitIsJqRefs`), 2026-11-11.
- **Resolution**: ADR-0015 now says one slot per open array or object, plus one while an object key's
  value is open; the reader rejects a `[` or `{` when the stack already holds 10 000.
